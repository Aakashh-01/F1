# F1 Client Trailer

Client-facing Remotion trailer built from Unity MCP gameplay captures.

## Commands

```powershell
npm run studio
npm run render
npm run still:opening
npm run still:mid
npm run still:closing
```

## Artifacts

- `out/F1ClientTrailer.mp4` is the rendered 60-second 1080p trailer.
- `stills/` contains the curated gameplay photo gallery and contact sheet.
- `public/stills/` and `public/audio/` are the assets used by Remotion.
